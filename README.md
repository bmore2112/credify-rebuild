# Credify — Rebuild

A unique, fully optimized rebuild of **getcredify.io** (a business-financing / lending brokerage), built with **Next.js 14 (App Router) + Tailwind + shadcn-style primitives**.

- **Theme:** "Gotham-noir" — cold blue-black canvas, steel-cyan accent.
- **Type:** Oxanium (all-caps futuristic display titles) + Exo 2 (professional body).
- **Pages:** Home, Solutions (9 industries), Apply (multi-step strategy-call form).
- **SEO/GEO:** JSON-LD (FinancialService/FAQ/Breadcrumb), sitemap, robots, `llms.txt`, security headers, a11y, static prerender.

## Run
```bash
cd site
npm install
npm run dev        # http://localhost:3000
npm run build && npm run start
```
